# バーコード解析リーダー (CodeReader)

ZXing（Zebra Crossing）ライブラリを利用し、**画像ファイルまたはカメラ**から各種一次元・二次元バーコード（Code 128、JAN / EAN、Code 39、NW-7、ITF、QRコード等）を読み取り、取得データの**最後の1桁を削除した値**を表示・コピーし、カードラボで商品情報を自動プレビューできるWebアプリケーションです。

---

## 🌟 主な機能

- **あらゆるバーコードに対応**:
  - Code 128, JAN / EAN-13, EAN-8, Code 39, Code 93, Codabar (NW-7), ITF, QRコード など
- **画像・カメラのハイブリッド読み取り**:
  - **画像ファイル**: フォルダ選択、ドラッグ＆ドロップ、クリップボード貼り付け（`Ctrl+V`）に対応（多段階リサイズ・回転補正付き高精度解析）。
  - **カメラ**: 背面カメラ対応のリアルタイムスキャン。
- **末尾1桁の自動削除**:
  - 読み取ったデータから最後の1文字を除去した値を生成。
- **快適なコピペ**:
  - ワンタップ「コピー」ボタン、および入力枠をクリックしての全選択コピー。
- **カードラボ検索連携（デバイス最適化）**:
  - **PCで利用時**: 読み取り完了時に、別タブを開かずに画面下部へカードラボの検索結果をそのまま埋め込みプレビュー（-350pxずらしで検索結果に直フォーカス）。
  - **スマホで利用時**: Netlify環境でも弾かれないよう、別タブでカードラボ公式ページを即座にオープン。
  - 「🔍 カードラボで検索して開く」ボタンで手動検索も可能。
- **📋 スキャン履歴**:
  - 読み取ったカードの履歴を自動記録（ブラウザを閉じても永続保存）。
  - 各行の「🔍」でいつでも別タブ再検索、「📋」で個別コピー、「🗑️」で削除。

---

## 🚀 起動方法

### おすすめ：ワンクリック起動（商品詳細ページへの自動ジャンプ対応）
1. フォルダ内の **`start.bat`** をダブルクリックします。
2. 自動でローカルサーバーが立ち上がり、ブラウザが起動します（`http://localhost:8000`）。
   ※ 商品詳細ページへの自動解決が有効になります。

### 手軽に使う場合（ファイル直開き）
1. **`index.html`** をそのままブラウザで開きます。
   ※ 検索結果一覧がプレビューに表示され、1クリックで詳細ページに遷移できます。

---

## 📱 スマホ（iPhone / Android）での利用
1. GitHub Pages や Cloudflare Pages、Netlify 等で **HTTPS** 公開します。
2. スマホのブラウザでアクセスすれば、カメラや写真ライブラリからそのまま快適に利用できます。
